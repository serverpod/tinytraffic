# Buildings

Fifteen toy-style buildings that match `../cars` and `../trees`: soft rounded volumes, chunky inset
windows, striped awnings, signs, balconies and busy rooftops. Each one is sized like one of the
City Kit buildings in `../game-assets`, so they can replace them tile for tile.

- `review.jpg`: every building from a 3/4 view.
- `street_day.jpg`, `street_night.jpg`: a street of them with the cars and trees, by day and at
  night with the lit windows and lamps glowing.

They are generated by `build_buildings.py` in Blender, so change the script and rebuild instead of
editing the GLBs:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P build_buildings.py
```

Add building names after `--` to build only those, and `--render DIR` to render them.

## Conventions

Same as `../game-assets`: 1 unit = 1 m, +Y up, the entrance faces **+Z** (the road), the pivot is
the centre of the footprint on `y = 0`. No glTF extensions and no textures: positions, normals,
16-bit indices and metallic-roughness materials.

## Nodes

```
building_<name>   root; glTF extras: size, footprint (tiles), wallMaterials, windowMaterials,
│                 litWindowMaterial ("WindowLit"), lampMaterials
└── building      one mesh, one primitive per material
```

## Materials

| Material | Use |
| --- | --- |
| `Wall` | The main facade colour. Recolour it to vary the city. |
| `WallB`, `WallC` | The second and third shopfronts' walls on `building_shops`. |
| `WallAccent` | Second wall colour: plinths, floor bands, pilasters, setbacks, shop surrounds. |
| `Window` | Window glass. |
| `WindowLit` | Window glass too (a shade lighter by day), on about a third of the panes, picked at random. Make it emissive at night for lit windows. |
| `Lamp` | Sign lettering, marquee bulbs, lanterns and antenna lights: emissive at night. |
| `Trim`, `Frame` | Cornices, sills, window frames, mullions, railings. |
| `Roof`, `Door`, `Awning`, `AwningStripe`, `Sign`, `Metal`, `Wood`, `Leaves`, `Flower` | Details. |

`Wall*`, `Window*` and `Lamp` are always their own materials. To save draw calls, the other
(decorative) materials are folded together when a building gives two of them the same colour,
keeping `Trim` if it is one of them and otherwise the first name alphabetically: on the cafe, for
example, the door uses `Awning`.

## Using them in the game

They aren't in `../game-assets` or the app yet. The game only places 1×1 buildings
(`GameAssets.buildings`) and sets them 0.8 m back from the road on 12 m lots, which all eleven
1×1 buildings here fit. They have two to three times the triangles of the City Kit
buildings (2.3k–4.9k for 1×1), so check the frame rate on the watch.
